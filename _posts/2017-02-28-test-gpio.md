### First program

This program sets pin 12 as an output with an initial value of High. Then I set it to Low, and finally back to High.

```python
#!/usr/bin/python
import RPi.GPIO as GPIO

GPIO.setmode(GPIO.BOARD)

GPIO.setup(12, GPIO.OUT, initial=GPIO.HIGH)

print(GPIO.input(12))

GPIO.output(12, GPIO.LOW)

print(GPIO.input(12))

GPIO.output(12, GPIO.HIGH)

print(GPIO.input(12))
```

See source [here](https://github.com/jluccisano/raspberry-scripts/blob/master/scripts/test-gpio.py)

1
